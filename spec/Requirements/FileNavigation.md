# 文件导航

返回[需求总览](Main.md)。配置与切换入口见[Subvault 管理](Subvaults.md)。

## 当前视图与显示根

`All` 显示完整 vault 的原生文件树。切换到 subvault 后，工作文件夹的直接内容显示在文件树顶层，其下层级按原生方式展开，工作文件夹本身由顶部标题表示。

文件树上方显示当前视图的图标和名称。该标题固定在文件列表滚动区域之外，文件滚动时保持可见。标题名称为只读显示。

Subvault 视图的内容依次为：

1. 工作文件夹内的原生文件树。
2. 外部已打开文件分组，与前面的内容具有清楚的分组边界，并可辨识其外部文件身份。

两个内容部分位于同一个滚动区域中。工作文件夹为空时仍可使用该视图，并通过文件导航创建内容。

## 原生文件树行为

- Subvault 内的文件、文件夹、层级和排列顺序，与以工作文件夹为根浏览原生文件树时一致。
- 排序随 Obsidian 原生排序设置调整；文件夹展开状态使用原生共享状态。
- 原生打开、选择、右键菜单、重命名、删除及拖动移动文件的行为保持一致。拖动移动操作改变真实文件路径。
- 原生的全部展开、全部折叠操作保持 Obsidian 自身的行为。
- 文件创建、删除、重命名与移动后，当前视图根据实际内容更新。

## 外部已打开文件

外部文件是当前工作区仍打开、且不在当前 subvault 工作文件夹内的真实文件。它们作为平铺的文件列表显示在内部内容之后，父文件夹不作为附加层级显示；悬停文件时可查看完整路径。

- 无论文件通过文件导航、链接、搜索或其他入口打开，只要符合上述条件，就进入外部文件分组。
- 同一路径打开在多个标签页中时仅显示一次，最后一个对应标签页关闭后从该分组移除。
- 已打开但尚未加载的文件标签页参与外部分组；反向链接、出链、大纲等辅助面板关联的文件不构成打开的文件标签页。
- 切换 subvault 后，依据新工作文件夹重新判断内外归属；属于当前 subvault 的文件只出现在内部文件树中。
- 打开或定位外部文件时，保持当前 subvault。文件导航中的定位落在对应外部文件项上。
- 外部文件项继续操作对应的真实文件，显示位置不改变其所属目录。
- 外部文件被重命名、移动或删除后，列表根据真实文件及仍打开的标签页更新。
- 没有外部文件时，外部分组及其分组边界一同消失。`All` 中的文件统一由完整文件树展示。

## 文件导航中的新建操作

| 操作入口 | 创建位置 |
| --- | --- |
| Subvault 文件导航工具栏的新建文件、新建文件夹 | 当前 subvault 的工作文件夹 |
| Subvault 文件列表空白处右键的新建文件、新建文件夹 | 当前 subvault 的工作文件夹 |
| 对内部子文件夹右键的新建操作 | 用户右键的子文件夹 |
| `All` 中的新建操作 | Obsidian 原生规则确定的位置 |
| 快捷键、命令面板及其他非文件导航入口 | 现有规则确定的位置 |

当前编辑器打开的是外部文件时，文件导航工具栏和空白处的新建位置仍为当前 subvault 的工作文件夹。创建成功后，新增内容按原生文件树规则显示。

## 状态记忆与恢复

- 在同一 vault 中保存 subvault 配置及排列顺序，重新打开后恢复上次选择的视图。
- `All` 和各 subvault 分别记住滚动位置，切换返回及重启后恢复；内容变化使原位置超出范围时，恢复到可用的滚动范围内。
- 文件夹展开状态由 Obsidian 统一管理，在 `All` 与重叠的 subvault 之间共享。切换视图本身不改写这份展开状态。
- 外部文件列表依据当前实际打开的文件生成；重启后根据 Obsidian 恢复的标签页重新确定。
- 左侧栏切换为其他面板后，再次显示文件导航时保持当前选择与相应状态。
- 文件导航在后台延迟加载时，插件随宿主正常加载后恢复视图；启动和重载保持其他面板的当前状态。

## 显示稳定性

切换 `All` 或 subvault 时，标题的占位保持稳定，图标与文字局部更新；标题不能短暂消失，文件区域不能先显示完整 vault 再变成目标内容。

局部内容或状态变化时，保留不受影响的滚动位置、展开状态和焦点。外部文件增减及外观修改应局部更新，不能使整个列表出现空白过渡、无关的滚动跳转或焦点丢失。切换视图按目标视图保存的滚动位置恢复。

## 验收场景

| 编号 | 场景与预期 |
| --- | --- |
| FN-01 | 分别使用 `All` 和某个 subvault，后者直接显示工作文件夹的内容；改变原生排序后，内部顺序与原生一致 |
| FN-02 | 使用空文件夹创建 subvault，视图可正常显示；通过工具栏或空白处新建后，实际文件位于该工作文件夹 |
| FN-03 | 从链接或搜索打开外部文件，当前 subvault 保持不变，外部分组出现对应文件；执行文件导航定位时仍留在该 subvault |
| FN-04 | 同一外部文件打开多个标签页，列表仅一项；关闭最后一个标签页后该项消失，最后一个外部文件消失时分组边界也消失 |
| FN-05 | 保持多个文件打开并切换到重叠的 subvault，内外归属重新计算，文件不在两个部分重复出现 |
| FN-06 | 编辑器打开外部文件时，工具栏和空白处新建仍落在 subvault 根；对子文件夹右键新建落在该子文件夹，其他入口遵循现有规则 |
| FN-07 | 在一个视图展开文件夹，进入能看到同一文件夹的其他视图时仍共享展开状态；原生全部展开、全部折叠正常工作 |
| FN-08 | 分别滚动 `All` 和多个 subvault，往返切换及重启后恢复对应位置与最后选择；其他左侧面板不会重置该状态 |
| FN-09 | 在较多文件、已展开层级及外部标签页并存时反复切换和增减标签页，标题稳定，文件区域无完整 vault 闪现或无关的滚动、焦点跳转 |
| FN-10 | 在原生文件导航中重命名、移动或删除内外文件，实际文件操作与列表更新一致；编辑器、标签页和其他面板不因 subvault 切换而重排 |
| FN-11 | 文件导航在后台延迟加载时启动或重载插件，保持当前面板且无错误通知；显示文件导航后自动恢复所选视图，标题与切换条各一份 |
| FN-12 | 辅助面板仍关联某个外部文件时，关闭该文件的最后一个标签页，外部分组立即移除该项；延迟加载的真实文件标签页仍显示，重载和切换视图后结果一致 |
