# Subvault 管理

返回[需求总览](Main.md)。文件树与状态恢复见[文件导航](FileNavigation.md)。

## 文件夹绑定与身份

- 每个 subvault 绑定 vault 内的一个现存文件夹，该文件夹是它的工作文件夹。
- 名称始终取工作文件夹的名称，由文件夹重命名操作更新。
- 同一文件夹路径只能对应一个 subvault。父子文件夹可以分别创建 subvault，不同路径下的同名文件夹也可以分别创建。
- 用户为每个 subvault 选择 Obsidian 提供的图标及一个预设颜色。图标和颜色共同用于识别同一个 subvault。
- 工作文件夹在创建时确定。创建后的管理操作包括修改图标、修改颜色和移除 subvault。

## 切换入口

- 文件导航显示时，底部提供 subvault 切换条，位于原生 vault 切换条上方。左侧栏显示其他面板时，subvault 切换条随文件导航一起隐藏。
- `All` 位于切换条最左侧，作为固定内置入口。用户创建的 subvault 使用各自的图标与颜色，新建项追加在已有项之后。
- 拖动 subvault 图标可以调整排列顺序，拖动期间显示插入位置；`All` 和创建入口保持固定。顺序保存后在重新加载插件或重启 Obsidian 时恢复，当前视图、文件树展开状态和滚动位置保持不变。
- 点击图标立即切换到对应视图，切换条明确标识当前选择。Subvault 图标的延迟悬停提示显示工作文件夹相对于 vault 根目录的完整路径，以区分同名文件夹；内置入口提示为 `All`。
- 图标超出可用宽度时，subvault 图标区域支持横向滚动，拖动到区域边缘时自动滚动以访问其他位置。`All` 和右侧创建入口保持可访问。
- 切换条右侧的创建入口打开创建面板。

## 创建流程

1. 创建面板占用文件导航区域，顶部提供图标选择与颜色选择两个操作。
2. 两个操作分别展开与 Obsidian 原生风格一致的选择区域；图标从适合表示不同用途的精简 Obsidian 图标集合中直接选择，列表顺序及滚动范围固定，选中项保留原位；颜色来自插件提供的预设色。
3. 主要区域始终显示 vault 的文件夹树，可展开层级、搜索并单选一个工作文件夹。
4. 底部提供 `Cancel` 和 `Create`。未选择有效且尚未绑定的工作文件夹时，不能完成创建。
5. 点击 `Create` 成功保存配置后，关闭创建面板，并进入新建的 subvault。
6. 点击 `Cancel` 放弃本次草稿，返回此前的文件导航视图及滚动位置。

创建面板提供可直接使用的初始图标与预设色。名称由所选文件夹确定。已绑定的文件夹不能重复创建，但仍可展开其下的文件夹并选择符合条件的子文件夹。侧栏缩窄时，操作文字保持在按钮内部，完整含义仍可通过控件提示获取。

## 外观管理与移除

右键某个 subvault 的切换图标，显示修改图标、修改颜色和 `Remove subvault` 操作。外观修改成功后，切换条与当前标题中的对应显示同步更新。

`Remove subvault` 移除该视图的配置，保留工作文件夹及其内容。移除当前 subvault 后切换到 `All`；移除其他 subvault 时保持当前选择。`All` 作为内置入口保留。

## 文件夹生命周期

| 文件夹变化 | Subvault 行为 |
| --- | --- |
| 工作文件夹重命名 | 保留该 subvault，更新路径及显示名称，保留图标、颜色与排列位置 |
| 工作文件夹在 vault 内移动 | 保留该 subvault，更新绑定路径 |
| 祖先文件夹重命名或移动 | 更新所有受影响 subvault 的绑定路径；各自名称仍取其工作文件夹名称 |
| 工作文件夹被删除 | 直接移除对应 subvault；当前选择被移除时返回 `All` |
| 祖先文件夹被删除 | 移除其下所有失去工作文件夹的 subvault；当前选择被移除时返回 `All` |

## 操作反馈

需要补充含义的控件使用英文的 Obsidian 风格延迟悬停提示。容器与空白区域保持安静，已充分表达操作含义的文字按钮使用自身标签。创建、外观修改和移除的完成反馈使用短暂通知；失败直接显示英文错误，不能显示成功反馈。

创建过程中，所选文件夹若已失效或已被绑定，应阻止提交并说明原因。配置保存失败时保留可继续操作的界面状态，创建草稿可供修正或重试。

拖拽排序在有效位置松开时提交。拖拽开始时关闭图标的悬停提示，拖拽期间不显示切换图标的提示，结束后恢复正常悬停。取消拖动或在切换区域外松开时保留原顺序；保存失败时显示错误并保留已保存的顺序。普通文件拖放不改变 subvault 排列。

## 主题适配

标题、切换条、创建面板和外观选择器在不同主题及深浅色模式下保持一致的布局与交互规则，配色与当前主题协调。Subvault 身份、当前选择、主要操作、禁用状态和键盘焦点均保持可辨识；主题切换及侧栏缩窄后，控件仍完整可用。
